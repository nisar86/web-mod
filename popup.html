Remove CSS Classes

Enter the classes you want to remove from page elements, separated by commas.

Syntax

• .class1 - removes class1 from elements that have it
• .class1 .class2 - removes class2 from elements inside class1
• .class1.class2 - removes class1 and class2 from elements with both
• .class1:-.class2 - removes ONLY class2 from class1 elements
• .class1:-.class2,.class3 - removes ONLY class2 and class3 from class1 elements

Options

• Apply: Removes classes and activates surveillance
• Stop: Stops surveillance (already removed classes stay removed)
• Save: Saves current text for next session
• Reset: Reloads the page, everything returns as before

Surveillance automatically re-removes classes if something adds them back (e.g. site scripts).

Shortcut

Alt+Shift+W open plugin
