# WebMod

Estensione Chrome per modificare il contenuto delle pagine web in tempo reale.

## Funzionalità

- **Rimuovi Classi CSS** - Rimuovi classi CSS indesiderate da qualsiasi pagina web
- **Modalità Sorveglianza** - Rimuove automaticamente le classi se vengono reimmunite da script del sito
- **Multilingua** - Disponibile in inglese e italiano
- **Scorciatoia da Tastiera** - Accesso rapido con Alt+Shift+W

## Utilizzo

Clicca il pulsante info all'interno dell'estensione per vedere sintassi e opzioni.

## Installazione

1. Clona il repository
2. Apri Chrome e vai su `chrome://extensions/`
3. Attiva "Modalità sviluppatore"
4. Clicca "Carica estensione non pacchettizzata" e seleziona la cartella dell'estensione
