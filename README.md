# WebMod

A Chrome extension to modify web page content in real-time.

## Features

- **Remove CSS Classes** - Remove unwanted CSS classes from any webpage
- **Surveillance Mode** - Automatically re-removes classes if they're added back by site scripts
- **Multilingual** - Available in English and Italian
- **Keyboard Shortcut** - Quick access with Alt+Shift+W

## Usage

Click the info button inside the extension to see syntax and options.

## Installation

1. Clone the repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension folder
